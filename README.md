# Lập trình hướng đối tượng (C#)

Bài tập môn Lập trình hướng đối tượng.

| Thư mục | Nội dung |
|---|---|
| `ThucHanhTuan01` | Thực hành tuần 1: lập trình cấu trúc (Bai01–Bai10, biến thể K = 0) |
| `BTTuan01` | Bài tập tuần 1: statement, operator, array (Bai01–Bai10) |
| `BTTuan03` | `SalesLib` (Customer, Order) + app console `BTTuan3` |
| `BTTuan04` | `GeoLib` (Point3D, Vector3D, TamGiac) + `GeoLibApp` |
| `BTTuan05` | WinForms: form đăng nhập + form thông tin sinh viên |
| `BTTuan06` | `GeoLib2D` + `GeoGebraApp` (WinForms, vẽ hình học 2D) |
| `Calculator` | Máy tính kiểu Windows Calculator (WinForms) + unit test MSTest |

Yêu cầu: .NET 10 SDK (các project WinForms chạy trên Windows).

```bash
dotnet run --project <thư mục project>
dotnet test Calculator/Calculator.slnx
```
